Importação de CSV rejeitada — o que verificar?

Confirmar se o arquivo possui cabeçalho com colunas data, descrição, valor e tipo; se as datas seguem o formato dd/mm/aaaa; e se o separador é vírgula. Orientar o usuário a exportar novamente pelo internet banking.

Usuário não consegue redefinir a senha

Verificar spam da caixa de entrada, validar o e-mail cadastrado e, se necessário, gerar token manualmente pelo endpoint administrativo.

Categorias incorretas após importação

O sistema aprende com as correções do usuário. Orientá-lo a ajustar a categoria manualmente — a preferência será aplicada nas próximas importações.
